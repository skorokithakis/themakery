I had GPT 6 Astra design a little box for a presence sensor I'm making. I described what I wanted in a few messages and this was the first thing it generated, and I have never had anything I made work so well first time. It is press-fit, and everything fit together perfectly: the ESP, the sensor, the lid, all of it, first time.

I didn't write a line of code or touch any CAD. I then did a few iterations later to change stuff, and after those iterations it fits perfectly.
